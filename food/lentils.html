Бобовые

Чечевица

Бобовые, которые быстро развариваются; для супов и гарниров.

чем полезен продукт

  • Витамин B9 (≈45 % нормы) — нужен для кроветворения; участвует в делении клеток.
  • Фосфор (≈26 % нормы) — нужен для крепких костей и зубов; помогает получать энергию из пищи.
  • Медь (≈25 % нормы) — помогает переносить железо по организму; нужна для нормальной соединительной ткани.

По правилам ЕС пользу нутриента можно указывать, если в 100 г продукта не меньше 15 % суточной нормы. Формулировки — из Регламента (ЕС) 432/2012.
